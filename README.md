# ตำบลพร้อมรับมือ

เว็บสาธารณะภาษาง่าย ๆ สำหรับชาวบ้าน อสม. ผู้นำชุมชน และองค์กรปกครองส่วนท้องถิ่น จังหวัดจันทบุรีและระยอง 134 ตำบล
บอกว่าตำบลของเราควรเตรียมพร้อมรับมือภัยแค่ไหน (5 ระดับ) เพราะอะไร และทำอะไรได้บ้าง

- ข้อมูล: ดัชนีความเปราะบางทางสังคม (SoVI) ฉบับทางการ ปี 2567 ของโครงการวิจัยการประเมินความเสี่ยงด้านภูมิอากาศจังหวัดระยองและจันทบุรี, หมู่บ้านประกาศเขตภัย ปี 2567 (ปภ.), ศูนย์พักพิง (ปภ.จังหวัด)
- ไม่แสดงอันดับและคะแนนดิบ แสดงเฉพาะระดับ เพื่อลดการตีตราพื้นที่
- เว็บวิชาการคู่กัน: https://juthasinee.github.io/SoVI-map/
- `build_data.py` สร้าง `data/tambons.json` และ `data/tambons.geojson` จากผลทางการของโครงการ (รันใหม่เมื่อข้อมูลเปลี่ยน)
- `data/opt_contacts.csv` เบอร์ อปท. จากแหล่งทางการ (กำลังรวบรวม)
